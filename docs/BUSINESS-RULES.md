# 业务规则

## 使用者

生物样本库管理员使用本工作台处理留存期限与保全优先级。

## 主规则

留存到期按月末夹紧计算，同意截止可缩短期限，保全标记优先阻止处置。

计算以整数最小单位或十进制定点数为准，避免二进制浮点在边界上漂移。无法完成前置校验的行进入隔离区；跨行规则在计算后标记阻断或人工复核。

## 判定

- `PASS`：业务结果在允许范围内。
- `REVIEW`：数据可计算，但需要人工确认或存在轻微偏离。
- `REJECT`：存在来源、守恒、方向或上限阻断，不能签发。

## 批次

同一来源重复执行得到同一批次数值。签发要求阻断项为零，并携带当前版本号；旧版本提交会被拒绝。证据只在签发后生成。

## 月度腾库计划

库房每月按**样品件数**限额，两份计划同时提交签发，规则如下：

1. 箱内只要有一件样品到月底仍不能处置（保全件、缺可处置日或可处置日晚于月末），整箱不排；本月只排“可腾空箱”。
2. 箱到期日 = 箱内最后一件样品的可处置日（取最大值）；存在不可处置件时到期日为空。
3. 排箱优先级：先在月限额内让**腾空箱数最多**；腾空箱数相同再比较箱到期日，到期早的优先；到期日相同按箱号兜底，结果唯一。
4. 两份计划同一箱只签入一份（互斥）；两份合计的去重样品件数不得超过月限额。
5. 同一 `request_key` 的签发请求幂等：重试直接返回首次批次，不重复写入、不重复占用额度。
6. 核对未通过（不可腾空箱入计划、同箱重叠、超限额、未达最优箱数或未按到期优先）返回 `CLEARANCE_GATE_BLOCKED`，不能签发。

核对接口与页面见 `docs/HTTP.md` 的“腾库计划”章节。
